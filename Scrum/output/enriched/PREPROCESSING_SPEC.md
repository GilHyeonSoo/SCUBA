# 장소 보강 데이터 전처리 규격서 (Enrichment Data Preprocessing Spec)

본 문서는 SCUBA 다이빙/프리다이빙 플랫폼의 장소 보강 데이터(`places-enriched.json`, `batch-*.json`)에 적용되는 **데이터 전처리(Preprocessing) 및 정규화(Normalization) 규칙**을 정의합니다.

웹 수집 및 Google Places API 등에서 취합된 비정형 데이터(영업시간, 가격, 수심, 수온, 시야 등)를 모바일 앱 UI 표출 및 PostgreSQL/Supabase DB 적재에 적합한 표준 규격으로 일관되게 변환합니다.

---

## 1. 전처리 원칙 (Core Principles)

1. **데이터 위조 금지 (Never Fabricate Data)**  
   원본 정보의 의미를 훼손하거나 추측에 의해 새로운 값을 임의 생성하지 않습니다. 신뢰할 수 없는 모호한 데이터는 원본을 보존합니다.
2. **검증 메타데이터 보존 (Preserve Provenance & Flags)**  
   모든 필드의 `sourceUrl`, `collectedAt`, `verified: true` 플래그 및 ID, 장소 타입, 네이버 플레이스 URL 등의 메타데이터는 무결하게 보존합니다.
3. **단일 포맷 원칙 (Deterministic Formatting)**  
   동일한 의미를 지닌 데이터는 항상 동일한 표기(24시간제 시간, 쉼표 단위 금액, 소문자 단위 기호 등)로 정규화됩니다.

---

## 2. 필드별 정규화 규칙 및 상세 예시

### 2.1 타임스탬프 (Timestamps)
- **대상 필드**: `enrichedAt`, 모든 `collectedAt`, `meta.enrichedAt`
- **변환 규칙**:
  - ISO 8601 UTC 형식 준수
  - 밀리초(`.xxx`)를 제거하고 초 단위 `Z` 접미사로 종료: `YYYY-MM-DDTHH:mm:ssZ`
  - 기존 필드 구조는 변경하지 않고 포맷만 정규화

| 원본 (Before) | 정규화 (After) |
|---|---|
| `2026-09-12T19:10:16.957Z` | `2026-09-12T19:10:16Z` |
| `2026-09-12T19:16:40.551Z` | `2026-09-12T19:16:40Z` |

---

### 2.2 영업시간 (Operating Hours)
- **대상 필드**: `pool.operatingHours.value`, `shop.operatingHours.value`
- **변환 규칙**:
  - Google Places의 요일별 텍스트(`월요일: 오전 10:00 ~ 오후 9:00; ...`)를 한국어 표준 압축 포맷으로 변환
  - 24시간제 `HH:mm` (한 자리 시는 0 패딩: `09:00`) 적용, `오전/오후` 문구 제거
  - 시작-종료 시간 사이는 공백 없는 물결표(`~`)로 통일
  - 요일별 동일 스케줄 그룹화 및 요약:
    - 7일 동일: `매일 10:00~21:00`
    - 평일/주말 분리: `평일 10:00~21:00, 주말 09:00~18:00`
    - 특정 요일 휴무: `화~일 11:00~19:00 (월요일 휴무)`
    - 평일 동일 + 토/일 상이: `평일 09:00~18:00, 토요일 09:00~13:00 (일요일 휴무)`
    - 24시간: `24시간 운영` (`24시간 영업` 표현 통일)

| 원본 (Before) | 정규화 (After) |
|---|---|
| `월요일: 오전 10:00 ~ 오후 9:00; 화요일: 오전 10:00 ~ 오후 9:00; ...; 일요일: 오전 10:00 ~ 오후 9:00` | `매일 10:00~21:00` |
| `월요일: 24시간 영업; 화요일: 24시간 영업; ...; 일요일: 24시간 영업` | `24시간 운영` |
| `월요일: 오전 10:00 ~ 오후 5:00; ...; 금요일: 오전 10:00 ~ 오후 5:00; 토요일: 오전 9:00 ~ 오후 6:00; 일요일: 오전 9:00 ~ 오후 6:00` | `평일 10:00~17:00, 주말 09:00~18:00` |
| `월요일: 휴무일; 화요일: 오전 11:00 ~ 오후 7:00; ...; 일요일: 오전 11:00 ~ 오후 7:00` | `화~일 11:00~19:00 (월요일 휴무)` |
| `월요일: 휴무일; 화요일: 오후 12:00~8:00; 수요일: 오후 12:00~8:00; 목요일: 휴무일; ...` | `화·수·금·토·일 12:00~20:00 (월요일, 목요일 휴무)` |
| `월요일: 오후 6:00 ~ 오전 12:00; ...; 일요일: 오전 11:00 ~ 오전 12:00` | `평일 18:00~24:00, 토요일 18:00~24:00, 일요일 11:00~00:00` |
| `평일 06:00 ~ 22:00 , 주말 09:00 ~ 18:00` | `평일 06:00~22:00, 주말 09:00~18:00` |

---

### 2.3 이용 요금 (Price Information)
- **대상 필드**: `pool.priceInfo.value`
- **변환 규칙**:
  - 금액 숫자에 천 단위 쉼표(`,`) 부여 (`15000원` → `15,000원`)
  - `입장료`, `입장권` 등 장황한 접미사를 간결한 표준형 `입장`으로 정규화
  - 가격 범위 표기 시 `~` 공백 제거 (`15,000원 ~ 20,000원` → `15,000~20,000원`)
  - 조건별 가격 분리 슬래시는 공백 포함 형식 준수 (`평일 33,000원 / 주말 44,000원`)
  - 부가 옵션 및 세부 조건(`(3시간 기준)`, `(탱크/웨이트 포함)`)은 괄호 보존

| 원본 (Before) | 정규화 (After) |
|---|---|
| `입장료 15,000원` | `입장 15,000원` |
| `1일 입장권 15,000원 ~ 20,000원` | `1일 입장 15,000~20,000원` |
| `스쿠버/프리다이빙 입장권 15,000원` | `스쿠버/프리다이빙 입장 15,000원` |
| `입장료 15,000원 (탱크/웨이트 포함 패키지 별도)` | `입장 15,000원 (탱크/웨이트 포함 패키지 별도)` |
| `평일 33,000원/주말 44,000원` | `평일 33,000원 / 주말 44,000원` |

---

### 2.4 수심 (Depth)
- **대상 필드**: `site.depthRangeM.value` (참고: `pool.maxDepthM`은 숫자 타입 유지)
- **변환 규칙**:
  - 단위는 소문자 `m`으로 통일 (`1M` → `1m`)
  - 수심 범위는 `최소~최대m` 형식으로 정규화 (`10m ~ 25m` → `10~25m`)
  - 단일 수심 수치는 숫자 뒤 `m` 결합 (`24` → `24m`)
  - 접두어(`최대`, `약`)가 있는 경우 공백 1칸 정규화 (`최대30m` → `최대 30m`)

| 원본 (Before) | 정규화 (After) |
|---|---|
| `10m ~ 25m` | `10~25m` |
| `5m ~ 35m` | `5~35m` |
| `1M` | `1m` |
| `최대30m` | `최대 30m` |
| `약 20m` | `약 20m` |

---

### 2.5 수온 (Water Temperature)
- **대상 필드**: `site.waterTemperature.value`
- **변환 규칙**:
  - 단위 기호는 항상 `°C`로 통일 (`℃`, `도` 치환)
  - 범위 표기: `최저~최고°C` 형식 준수 (`10°C ~ 21°C` → `10~21°C`)
  - 단일/추정 수온: `약 20°C` 또는 `22°C`

| 원본 (Before) | 정규화 (After) |
|---|---|
| `10°C ~ 21°C` | `10~21°C` |
| `14°C ~ 24°C` | `14~24°C` |
| `약 20도` | `약 20°C` |
| `18-24℃` | `18~24°C` |

---

### 2.6 시야 (Visibility)
- **대상 필드**: `site.visibility.value`
- **변환 규칙**:
  - 가시거리 범위: `최소~최대m` 형식 (`5m ~ 15m` → `5~15m`)
  - 정성적 한국어 표현(`좋음`, `보통`, `우수` 등)은 그대로 보존

| 원본 (Before) | 정규화 (After) |
|---|---|
| `5m ~ 15m` | `5~15m` |
| `10m ~ 25m` | `10~25m` |
| `약 10m` | `약 10m` |
| `보통` | `보통` |

---

### 2.7 난이도 (Difficulty)
- **대상 필드**: `site.difficulty.value`
- **변환 규칙**:
  - 표준 4단계: `초급`, `중급`, `고급`, `전문가`
  - 동의어 매핑: `초급자`/`beginner` → `초급`, `중급자` → `중급`, `고급자` → `고급`
  - 복합/범위 난이도: `초급 ~ 중급` → `초급~중급`, `중급 ~ 고급` → `중급~고급`, `초급 ~ 고급` → `초급~고급`

| 원본 (Before) | 정규화 (After) |
|---|---|
| `초급 ~ 중급` | `초급~중급` |
| `중급 ~ 고급` | `중급~고급` |
| `초급 ~ 고급` | `초급~고급` |
| `초급자` | `초급` |
| `고급자` | `고급` |

---

### 2.8 제공 서비스 (Shop Services)
- **대상 필드**: `shop.services.value` (string array)
- **표준 레이블 7종**:
  1. `스쿠버 교육`
  2. `프리다이빙 교육`
  3. `장비 렌탈`
  4. `다이빙 투어`
  5. `장비 판매`
  6. `공기 충전`
  7. `나이트록스`
- **변환 규칙**:
  - 동의어 정규화:
    - `스쿠버다이빙 교육`, `스킨스쿠버 교육`, `스쿠버 강습` → `스쿠버 교육`
    - `프리다이빙 강습` → `프리다이빙 교육`
    - `장비 대여`, `다이빙 장비 렌탈` → `장비 렌탈`
    - `다이빙 장비 판매` → `장비 판매`
    - `국내외 투어` → `다이빙 투어`
    - `공기통 충전`, `탱크 충전` → `공기 충전`
  - 배열 내 중복 제거 (Deduplication)
  - 표준 순서(1~7번) 기반 안정적 정렬(Stable Sort)

| 원본 (Before) | 정규화 (After) |
|---|---|
| `["다이빙 투어", "스쿠버다이빙 교육", "다이빙 장비 판매", "장비 렌탈"]` | `["스쿠버 교육", "장비 렌탈", "다이빙 투어", "장비 판매"]` |

---

### 2.9 이미지 URL (Image URLs)
- **대상 필드**: `images[].url`, `images[].sourcePageUrl`
- **변환 규칙**:
  - HTML 엔티티 치환: `&amp;` → `&`
  - 전후 공백 제거(trim)

| 원본 (Before) | 정규화 (After) |
|---|---|
| `https://.../photo?size=small&amp;format=webp` | `https://.../photo?size=small&format=webp` |

---

### 2.10 자유 텍스트 (Free Text)
- **대상 필드**: `shortDescription.value`, `notes`, `pool.poolSize.value`, `pool.reservationMethod.value`, `site.accessType.value`, `site.currentInfo.value`
- **변환 규칙**:
  - 연속된 다중 공백(`\s{2,}`)을 단일 공백(`' '`)으로 압축
  - 문자열 앞뒤 공백 제거(trim)

## 3. 파이프라인 파일 및 백업 체계

```
Scrum/output/enriched/
├── places-enriched.raw.json           # 원본 백업 파일 (초회 실행 시 자동 보관)
├── places-enriched-preprocessed.json  # 전처리 완료 전체 데이터
├── places-enriched.json               # 성공 완료 후 교체된 정규화 데이터 (DB 임포트용)
├── preprocess-report.json             # 전처리 수행 통계 및 Before/After 샘플
├── batch-001.json ~ batch-023.json    # 분할 배치 정규화 동기화
└── PREPROCESSING_SPEC.md              # 본 전처리 규격서
```

---

## 4. CLI 실행 및 검증 명령어

`Scrum/package.json`에 등록된 npm 스크립트를 통해 원클릭으로 전처리를 수행합니다.

```bash
# Scrum 디렉토리 내부에서 실행
pnpm preprocess:enrichment
# 또는
npm run preprocess:enrichment
```
